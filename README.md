# Sistema-de-Torneios-ACCA
Sistema de Gerenciamento de Inscrições e Chaveamento para a Associação Corpo e Arte Darcilei Monteiro de Oliveira

## Execução local

Se você quiser rodar sem Turso, defina `DB_MODE=local` ou `USE_LOCAL_DB=true` antes de iniciar a aplicação. Nesse modo o projeto usa `data.sqlite` na raiz do repositório e recria o schema automaticamente quando necessário.
